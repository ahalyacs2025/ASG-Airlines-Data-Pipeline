# ASG-Airlines-Data-Pipeline
## Project Overview
End-to-end airline data engineering pipeline for data cleaning,
quality validation, KPI generation and Power BI reporting.

## Key KPIs
- Average Flight Duration
- Route-wise Flight Traffic
- Flight Anomalies
- Flight Distribution by Airline
- Overnight Flights

## Technologies
- Python / Pandas
- Google Colab
- Power BI
- GitHub

## Project Files
- ASG_airlines_pipeline (1).ipynb – data pipeline
- cleaned_flights.csv – cleaned flight dataset
- protected_passengers.csv – PII-protected passenger data
- route_traffic.csv – route traffic aggregation
- anomaly_summary.csv – anomaly summary
- airline_distribution.csv – airline distribution
- ASG_Airlines_Dashboard.pbix – Power BI report
- Project_Documentation.docx – detailed documentation
